Tạo replay Taiko từ file .osz

Chọn file .osz của bạn, sau đó chọn difficulty Taiko và checkpoint. Mỗi job chạy nguyên bài và có thể mất nhiều phút; không dùng chart để train thêm.

Sẵn sàng.

Giới hạn: file tối đa 128 MB, map dưới 10 phút, một job GPU mỗi lần. File bạn gửi được lưu trên server để tạo replay; chỉ tải lên beatmap bạn có quyền chia sẻ. Nếu .osz có nhạc được chart tham chiếu, replay sẽ kèm nhạc.
